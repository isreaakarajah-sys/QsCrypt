# QsCrypt

**خزنتك المشفّرة على Android وسطح المكتب.**

- يفتح ويُنشئ حاويات وأقراصاً بصيغ **VeraCrypt** و**TrueCrypt** و**BitLocker**.
- له صيغته الخاصة **QsCrypt**: تشفير بثلاث طبقات (AES-256 ← Twofish-256 ← XChaCha20-Poly1305) مع Argon2id، ومشاركة مربوطة بالأجهزة مقاومة للحوسبة الكمومية.

> مشروع خاص، قيد التطوير. لا يتصل بالإنترنت ولا يطلب صلاحية `INTERNET`.

## ما يعمل الآن (الإصدار الأول 1.0)

- **VeraCrypt وTrueCrypt:**
  - فتح الحاويات وإنشاؤها، مع المجلد المخفي وحمايته، وملفات المفاتيح، وPIM.
  - تغيير كلمة المرور، ونسخ الترويسة احتياطياً.
- **BitLocker:**
  - فتح أقراص ويندوز بكلمة المرور أو مفتاح الاسترداد.
  - إنشاء حاوية VHD يفتحها ويندوز مباشرة، أو تشفير فلاشة كاملة.
- **فلاشات وهاردات USB** عبر OTG مباشرة، دون روت.
- **صيغة QsCrypt:** ملفات وحاويات.
  - الربط بجهات الاتصال برمز QR (X25519 + ML-KEM-768).
  - التوقيع.
  - مزايا الحماية كلها، مطفأة افتراضياً.
- **أنظمة الملفات:** FAT وexFAT قراءة وكتابة، وNTFS قراءة.
- **إدارة الملفات:**
  - عدة خزنات معاً.
  - نسخ ونقل ولصق بينها وبين الجهاز والفلاشة.
  - مجلدات كاملة.
- **عارض الصور والفيديو والصوت وPDF** داخل الخزنة، دون نسخة غير مشفّرة على القرص.
- **عمليات في الخلفية** تُوقف مؤقتاً وتُستأنف، و**فحص الخزنة وإصلاحها**، و**اختبار السرعة**.
- **ملف مشفّر يبدو صورة عادية**، والإخفاء داخل البكسلات، و**رسائل سرية برمز QR**، و**وضع التمويه** كآلة حاسبة تعمل.
- **القفل:**
  - رمز أو نمط أو البصمة وحدها، ومصادقة ثنائية.
  - قفل عند مغادرة التطبيق، ورمز طوارئ يفتحه فارغاً.
  - فتح الخزنات المفضلة بالبصمة.
  - سجل المحاولات الفاشلة.
  - إغلاق تلقائي، ومنع لقطات الشاشة.
- **«ملفاتي»:** ملفات الهاتف كمدير ملفات، وتشفيرها إلى خزنة دفعة واحدة.
- **نسخة احتياطية مشفّرة** للهوية وجهات الاتصال وقائمة الخزنات، و**سجل تشخيص** محلي.

## بنية المستودع

| المجلد | المحتوى |
|---|---|
| `core/crates/qscrypt-core` | المحرك بلغة Rust: الصيغ وأنظمة الملفات، دون اعتماديات |
| `core/crates/qscrypt-crypto` | خوارزميات الإنتاج (RustCrypto) |
| `core/crates/qscrypt-ffi` | طبقة الربط مع Android (JNI) |
| `core/testdata` | متجهات وحاويات اختبار مولّدة بتطبيق Python مستقل |
| `android/` | تطبيق Android بـ Kotlin وJetpack Compose |
| `brand/` | ملفات الهوية البصرية |
| `.github/workflows/` | البناء والاختبار التلقائي |

## الاختبارات

```sh
cd core && cargo test --workspace --release
python3 core/testdata/gen_vectors.py   # يعيد توليد المتجهات وحاويات الاختبار
```

## الحصول على التطبيق

كل تعديل على الفرع `main` يبني تلقائياً ثلاث نسخ APK في صفحة **Releases**:

- `modern-arm64` للهواتف الحديثة.
- `old-phones-armv7` للهواتف القديمة (32-بت).
- `universal` لكل الهواتف.

ركّب النسخة على الجوال بعد السماح بتثبيت التطبيقات من مصادر خارجية.
